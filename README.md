## ⚡ 核心功能與亮點 (Key Features)

1. **實時精準動態時鐘 (Real-time Chrono Clock)**：
   - 時、分、秒每秒動態跳動更新，秒數具備呼吸微光與發光質感。
   - 完整在地化中文日期（如：`2026 年 9 月 16 日 星期三`）。
   - 今日已度過百分比進度條（精確反映一日 86,400 秒流逝）。
   - 支援 12H (AM/PM) / 24H 制即時切換。
2. **智慧情境問候與時區聯動**：
   - 依當前時段（晨曦、早晨、午後、傍晚、深夜）智慧切換問候語與身心狀態建議。
   - 跨時區聯動時鐘看板（台北 GMT+8、東京 GMT+9、倫敦 GMT+1、舊金山 GMT-7）。
3. **極致視覺美學 (Modern Glassmorphism)**：
   - 星空深黑背景、多重動態環境流光、半透明毛玻璃層次與柔和邊框。
   - 專屬形象卡片支援 3D 視差傾斜 (Parallax Tilt) 互動微動態。
4. **豐富完整內容模組**：
   - 關於我、專業技能樹矩陣、精選專案櫥窗、一鍵複製 Email 聯繫卡片。
   - 100% 響應式設計 (RWD)，完美適應手機、平板與寬螢幕。

## 🚀 本地端運行方式 (Local Setup)

本專案採用純原生輕量化技術建構（HTML5 + Vanilla CSS + 原生 JavaScript），無繁重依賴，秒開載入：

1. **複製倉庫**：
   ```bash
   git clone https://github.com/bogerneal/hahaisme.git
   cd hahaisme
   ```

2. **啟動本機伺服器**（可任選以下方式）：
   - 使用 Python：
     ```bash
     python -m http.server 8080
     ```
   - 或使用 Node.js：
     ```bash
     npx serve
     ```
   - 或直接在瀏覽器中開啟 `index.html` 檔案即可！

3. **瀏覽網站**：  
   在瀏覽器開啟 `http://localhost:8080`
